# Архитектура

## Слои

```text
React + TypeScript (Vite)
          │ /api
          ▼
Fastify API (127.0.0.1:3000)
          ├── Server manager / source probe
          ├── GoodPrice adapter boundary
          ├── Normalized snapshot importer
          ├── Direct Opportunity Engine
          ├── Multi-step Route Engine
          ├── Product & history queries
          └── Local event journal
                    │
                    ▼
            SQLite + Drizzle schema
```

## Frontend

`src/App.tsx` содержит разделы панели, таблицы и рабочие действия по управлению серверами, импорту нормализованных снимков, поиску маршрутов с заданным капиталом и изменению параметров аналитики. `src/lib/api.ts` — единственная точка вызова локального backend API. Секретные токены не возвращаются frontend.

## Backend

- `server/index.ts` — HTTP API, валидация входных данных, журналирование.
- `server/services/goodprice.ts` — граница внешнего источника; диагностический запрос не предполагает структуру API.
- `server/services/crypto.ts` — локальное шифрование секретов.
- `server/domain/money.ts` — fixed-point арифметика на `bigint`.
- `server/engine/opportunities.ts` — независимые алгоритмы прямых сделок, маршрутов и межсерверных ценовых различий.
- `server/schema.ts` и `server/db.ts` — Drizzle-схема и инициализация SQLite.
- `shared/types.ts` — общие DTO и доменные модели.

## Поток данных

1. Пользователь добавляет сервер.
2. Менеджер подключений проверяет настроенный URL, не отправляя токен неизвестным способом.
3. Источник должен быть исследован, а его предложения преобразованы в `MarketOffer`.
4. Нормализованный снимок проходит Zod-валидацию и сохраняется в `offers`; каждое наблюдение добавляется в `price_history`.
5. `Opportunity Engine` получает единый массив предложений и отдельно запускает прямой поиск, поиск валютных циклов и межсерверное сравнение.
6. Интерфейс показывает источник, временную метку и тип котировки.

## Хранилище

SQLite-файл создаётся локально в `./data/ecointer.sqlite` (или по `DATABASE_PATH`). WAL включён. Основные lookup-поля предложений и история индексированы.

## Границы текущей реализации

Пока нет проверенного ответа GoodPrice, расписание автоматического обновления не подключено к несуществующему API-контракту. Импорт нормализованных снимков позволяет тестировать хранение и аналитику без фальшивых данных. Отдельные подсистемы расширенного прогнозирования, полный журнал симуляций и UI-комиссий находятся за пределами реализованного среза и не обозначаются как готовые.
