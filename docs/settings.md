# Настройки

## Реализованные параметры Opportunity Engine

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `maxOperations` | 6 | Максимум операций; покупка и продажа одной ступени считаются двумя операциями |
| `maxUniqueItems` | 6 | Максимум уникальных товаров в маршруте |
| `maxIntermediateCurrencies` | 4 | Максимум промежуточных валют |
| `maxResults` | 100 | Максимум возвращаемых результатов |
| `maxCombinations` | 25 000 | Ограничитель перебора рёбер маршрута |
| `maxDurationMs` | 2 000 | Максимальная длительность поиска маршрутов |
| `minProfit` | `0` | Минимальная чистая прибыль |
| `minRoiPercent` | `0` | Минимальная доходность в процентах |
| `maxQuoteAgeSeconds` | 900 | Максимальный возраст котировки |
| `startingCapitalByCurrency` | не задан | Бюджет на каждую стартовую валюту |
| `maxStartingCapital` | не задан | Ограничение начального капитала |

## Серверы и обновление GoodPrice

У каждого сервера собственные имя, URL игрового сервера, URL GoodPrice, world ticket, приоритет и интервал обновления. После сохранения токена ECOInter может синхронизировать рынок вручную по кнопке или автоматически по интервалу. По умолчанию интервал равен 300 секундам.

Синхронизация запрашивает `/api/v1/plugins/GoodPrice/stores` с заголовком `X-Auth-Token`. При HTTP 401/403 автоматическое повторение останавливается до замены токена. Токен GoodPrice действует примерно 24 часа.

## Комиссии

Структура `feesByServer` в настройках аналитики поддерживает индивидуальные проценты, налог и фиксированные сборы. В текущем интерфейсе есть редактирование глубины анализа и фильтров; полноценная форма настройки комиссий ещё не добавлена. Пока не задано — комиссия равна нулю.

## Капитал

`startingCapitalByCurrency` хранит стартовый капитал отдельно по валютам, например:

```json
{ "RELAX": "150", "GOLD": "80" }
```

Не объединяй разные валюты вручную. В конструкторе маршрутов можно искать циклы с отдельным стартовым активом и бюджетом.

## Безопасные значения

- HTTP не шифрует world ticket при передаче; предпочтителен HTTPS.
- Настройки и котировки сохраняются локально.
- Неизвестные комиссии не применяются автоматически.
- Межсерверная разница не считается исполнимым маршрутом без подтверждённого механизма переноса активов.
