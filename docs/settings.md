# Настройки

## Реализованные параметры Opportunity Engine

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `maxOperations` | 6 | Максимум операций; покупка и продажа одной ступени считаются двумя операциями |
| `maxUniqueItems` | 6 | Максимум уникальных товаров в маршруте |
| `maxIntermediateCurrencies` | 4 | Максимум промежуточных валют |
| `maxResults` | 100 | Максимум возвращаемых результатов на тип поиска |
| `maxCombinations` | 25 000 | Ограничитель перебора ребер маршрута |
| `maxDurationMs` | 2 000 | Максимальная длительность поиска маршрутов |
| `minProfit` | `0` | Минимальная чистая прибыль в валюте результата |
| `minRoiPercent` | `0` | Минимальная доходность в процентах |
| `maxQuoteAgeSeconds` | 900 | Максимальный возраст котировки |
| `startingCapitalByCurrency` | не задан | Бюджет на каждую стартовую валюту |
| `maxStartingCapital` | не задан | Ограничение начального капитала |

## Серверы

У каждого сервера собственные имя, URL игрового сервера, URL GoodPrice, токен, приоритет и интервал обновления. В текущей версии проверка URL доступна, но плановое обновление ещё не привязано к непроверенному API GoodPrice.

## Комиссии

Структура `feesByServer` в настройках аналитики уже поддерживает индивидуальные проценты, налог и фиксированные сборы. В текущем интерфейсе добавлено редактирование глубины анализа и фильтров; полноценная форма настройки комиссий в следующих изменениях должна быть добавлена отдельно. Пока не задано — комиссия равна нулю.

## Капитал

`startingCapitalByCurrency` хранит стартовый капитал отдельно по валютам, например:

```json
{ "RELAX": "150", "GOLD": "80" }
```

Не объединяйте разные валюты вручную. В конструкторе маршрутов можно искать циклы с отдельным стартовым активом и бюджетом.

## Безопасные значения

- HTTP URL должен отображаться как небезопасный.
- Настройки не отправляются во внешние аналитические системы.
- Неизвестные комиссии не применяются автоматически.
- Источник, который ответил HTTP, но не прошёл проверку структуры, не считается интегрированным.
