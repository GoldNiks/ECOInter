# Решение проблем

## GoodPrice отвечает, но API не подтверждён

Кнопка «Проверить API» обращается к `/api/v1/plugins/GoodPrice/stores`, а не только открывает HTML-страницу. Убедись, что URL в карточке имеет вид `http://HOST:PORT/plugin/GoodPrice`, плагин включён на сервере и его версия совместима.

## Требуется world ticket (HTTP 401/403)

Скопируй world ticket из GoodPrice: DevTools встроенного браузера → Application → Local Storage → `worldTicketData` → `worldTicket`. Сохрани его в карточке сервера ECOInter. Токен действует примерно 24 часа; после истечения замени его свежим.

Токен передаётся в заголовке `X-Auth-Token`. Не используй токен авторизации Eco SLG или пароль аккаунта.

## HTTP 404 от API GoodPrice

Плагин GoodPrice может быть не установлен, выключен либо API путь отличается в используемой версии. Ожидаемый путь: `/api/v1/plugins/GoodPrice/stores`.

## Не удаётся сохранить токен

ECOInter автоматически создаёт ключ `data/master.key` при первом запуске и хранит токен в SQLite зашифрованным. Проверь, что процесс может записывать файлы в папку `data`. Не удаляй `master.key`, пока база содержит зашифрованный токен. Генерировать мастер-ключ вручную не требуется.

## Рынок не синхронизируется

Проверь, что world ticket сохранён, затем нажми «Синхронизировать рынок». При HTTP 401/403 обнови токен. При HTTP 404 проверь плагин и URL. Другие ошибки записываются в локальный журнал событий. Автоматическое обновление использует интервал, указанный в карточке сервера.

## JSON отклонён при импорте

Проверь, что структура соответствует `ecointer.market.v1` из `docs/goodprice-api.md`, `serverId` указывает на ранее добавленный сервер, денежные значения являются десятичными строками с точностью до 8 знаков, а количество — положительным целым числом.

## Возможностей не найдено

Проверь наличие импортированных предложений обоих типов:

- `buy` — пользователь покупает товар у магазина;
- `sell` — пользователь продаёт товар магазину.

Для прямой сделки предложения должны совпадать по товару, серверу и валюте. Для многоэтапного маршрута каждая ступень связывает разные валюты через один товар на одном сервере. Котировки старше `maxQuoteAgeSeconds` исключаются.

## `pnpm build` не проходит

Проверь Node.js 20+, затем повтори `pnpm install`. Для диагностики используй `pnpm typecheck`. Если ошибка связана с native module `better-sqlite3`, установи поддерживаемую версию Node.js LTS и повтори установку зависимостей.

## Где находятся локальные данные

По умолчанию база: `./data/ecointer.sqlite`, ключ: `./data/master.key`. Сохраняй оба файла при переносе ECOInter на другой компьютер, иначе зашифрованный токен нельзя будет восстановить.
