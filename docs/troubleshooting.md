# Решение проблем

## `Connection refused` при проверке GoodPrice

Это означает, что TCP-соединение не было установлено. Проверьте IP/порт, доступность сети, firewall и работу сервиса. Это не доказывает ошибку токена или формат URL. До получения ответа API не выполняйте догадки об endpoint-ах.

## `TOKEN_NOT_SENT` / токен сохранён, но не отправлен

Так и задумано до подтверждения фактического способа авторизации GoodPrice. Укажите `ECOINTER_MASTER_KEY` для локального зашифрованного хранения, но не пробуйте наугад `Bearer`, query token или произвольный заголовок.

## Не получается сохранить токен

Сгенерируйте мастер-ключ:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Добавьте его в `.env` под именем `ECOINTER_MASTER_KEY` и перезапустите backend. Не сохраняйте `.env` в репозитории.

## JSON отклонён при импорте

Проверьте, что структура соответствует `ecointer.market.v1` из `docs/goodprice-api.md`, `serverId` указывает на ранее добавленный сервер, денежные значения являются десятичными строками с точностью до 8 знаков, а количество — положительным целым числом.

## Возможностей не найдено

Проверьте наличие предложений обоих типов:

- `buy` — пользователь покупает товар;
- `sell` — пользователь продаёт товар.

Для прямой сделки предложения должны совпадать по товару, серверу и валюте. Для многоэтапного маршрута каждая ступень связывает разные валюты через один товар на одном сервере. Котировки старше `maxQuoteAgeSeconds` исключаются.

## `pnpm build` не проходит

Проверьте Node.js 20+, затем повторите `pnpm install`. Для диагностики используйте `pnpm typecheck`. Если ошибка связана с native module `better-sqlite3`, установите поддерживаемую версию Node.js LTS и повторите установку зависимостей.

## Где находится база данных

По умолчанию `./data/ecointer.sqlite`. Путь задаётся через `DATABASE_PATH`.
