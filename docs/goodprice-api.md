## Что делает адаптер сейчас

`server/services/goodprice.ts` предоставляет безопасную диагностическую проверку заданного URL. Она сообщает HTTP-статус, content-type и время ответа, если соединение доступно, но выставляет `verified: false`, потому что доступность страницы сама по себе не подтверждает формат данных.

Адаптер **не**:

- перебирает предположительные API endpoint-ы;
- подставляет токен в неизвестный заголовок или query-параметр;
- трактует HTML или непроверенный JSON как рыночные предложения;
- преобразует справочную цену в исполнимую цену покупки/продажи.

Если токен задан, он сначала шифруется локально, но не отправляется на URL до подтверждения схемы авторизации. Так исключается случайная передача секрета в неправильном формате.

## Внутренний контракт импорта ECOInter

До появления достоверной схемы GoodPrice предусмотрен отдельный **внутренний** JSON-контракт `ecointer.market.v1`. Это контракт ECOInter для импорта уже нормализованных данных; он не объявляется форматом GoodPrice.

Пример структуры:

```json
{
  "schemaVersion": "ecointer.market.v1",
  "sourceId": "manual-import",
  "serverId": "<id сервера, добавленного в ECOInter>",
  "capturedAt": "2026-11-10T19:00:00.000Z",
  "offers": [
    {
      "id": "offer-unique-id",
      "serverId": "<тот же id сервера>",
      "itemId": "game-item-id",
      "itemName": "Название предмета",
      "action": "buy",
      "currency": "RELAX",
      "totalPrice": "150",
      "quantity": 3,
      "quoteKind": "listing",
      "observedAt": "2026-11-10T19:00:00.000Z",
      "sourceId": "manual-import"
    }
  ]
}
```

Семантика нормализованного контракта:

- `action: "buy"` — стоимость, которую пользователь должен заплатить, чтобы купить товар (ask/offer продавца).
- `action: "sell"` — сумма, которую пользователь получит, продавая товар по предложению (bid/offer покупателя).
- `totalPrice` — сумма за весь `quantity`, а не цена одной единицы. Это позволяет не терять точность на пакетных сделках.
- `quoteKind: "listing"` означает предложение с ценой и количеством; `reference` — справочную/оценочную котировку. Подтверждение исполнимости всё равно зависит от фактической природы источника.
- `quantity` — целое положительное доступное количество.
- Денежное значение — десятичная строка до 8 знаков после запятой.

## Следующие действия для завершения GoodPrice Adapter

Когда источник станет доступен:

1. Открыть страницу в браузере и записать Network HAR при загрузке и при изменении фильтров.
2. Разделить навигационные запросы, конфигурационные запросы и запросы с рыночными данными.
3. Повторить запросы без токена и с тем способом авторизации, который реально использует сама страница.
4. Установить, возвращает ли GoodPrice справочные цены или реальные ask/bid предложения с количеством.
5. Проверить пагинацию, повторяющиеся записи, лимиты частоты и коды ошибок.
6. Сопоставить фактические поля с `MarketOffer` и добавить контрактные тесты на сохранённые реальные ответы.
7. Только после этого включить автоматическую синхронизацию.

До выполнения этих шагов GoodPrice остаётся **непроверенным источником**, а не работающей интеграцией.
