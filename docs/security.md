# Безопасность

## Локальная поверхность приложения

Backend по умолчанию слушает только `127.0.0.1:3000`, Vite — `127.0.0.1:5173`. Не публикуйте эти порты в локальную сеть без отдельной аутентификации и настройки доступа.

## Токены

- Токен не возвращается API в открытом виде.
- Перед сохранением он шифруется AES-256-GCM.
- Ключ берётся из `ECOINTER_MASTER_KEY`, который должен находиться в локальном `.env`, а не в SQLite или Git.
- Если ключ не задан, сохранение токена отклоняется.
- Токены и заголовки авторизации маскируются в логах.
- Пока реальный способ авторизации GoodPrice не установлен, токен не отправляется внешнему адресу.

Потеря мастер-ключа означает невозможность расшифровать ранее сохранённые токены. Храните его отдельно от резервной копии базы.

## HTTP / HTTPS

Исходный URL GoodPrice использует HTTP. Такой канал не шифрует сетевой трафик и не защищает токен от перехвата. До появления HTTPS и подтверждения схемы авторизации не отправляйте секреты по этому адресу.

## Локальность

- Рыночные данные и настройки сохраняются в SQLite на компьютере пользователя.
- В проекте нет сторонних аналитических SDK.
- UI не загружает внешние web-fonts.
- Автоматическая торговля не производится.

## Импорт JSON

JSON импорта проходит Zod-валидацию. Используйте только данные, полученные из доверенного источника. Не импортируйте непроверенные файлы с потенциально огромными количествами или некорректными ценами.
