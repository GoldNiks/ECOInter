# Безопасность

## Локальная поверхность приложения

Backend по умолчанию слушает только `127.0.0.1:3000`, Vite — `127.0.0.1:5173`. Не публикуйте эти порты в локальную сеть без отдельной аутентификации и настройки доступа.

## World ticket GoodPrice

- Для GoodPrice используется world ticket в заголовке `X-Auth-Token`.
- Это не токен авторизации игрового сервера Eco и не пароль от аккаунта.
- Токен извлекается из GoodPrice: DevTools встроенного браузера → Application → Local Storage → `worldTicketData` → `worldTicket`.
- Срок действия указанного токена — около 24 часов; при HTTP 401/403 его нужно заменить.
- Токен никогда не возвращается API ECOInter в открытом виде и маскируется в логах.

## Хранение токена

Перед сохранением токен шифруется AES-256-GCM. При первом запуске ECOInter автоматически создаёт случайный 32-байтовый ключ `data/master.key`. Пользователь не должен генерировать или вводить его вручную.

Ключ и база данных находятся локально. Папка `data/`, файл ключа и база SQLite исключены из Git. Не удаляйте `data/master.key`, пока в базе есть зашифрованный токен: без исходного ключа расшифровать сохранённый токен будет невозможно. При резервном копировании сохраняйте ключ отдельно и защищённо вместе с резервной копией базы.

## HTTP / HTTPS

Передача world ticket в заголовке `X-Auth-Token` на адрес `http://...` не защищена TLS. AES-256-GCM защищает токен **на диске**, но не шифрует сетевой запрос между ECOInter и сервером GoodPrice.

Используй HTTP только в доверенной сети. Для внешнего или недоверенного соединения настрой HTTPS reverse proxy и подключайся через HTTPS, если серверная инфраструктура это позволяет.

## Локальность

- Рыночные данные и настройки сохраняются в SQLite на компьютере пользователя.
- В проекте нет сторонних аналитических SDK.
- UI не загружает внешние web-fonts.
- Автоматическая покупка и продажа не производится; ECOInter только загружает котировки и анализирует их.

## Импорт JSON

JSON импорта проходит Zod-валидацию. Используйте только данные из доверенного источника. Не импортируйте непроверенные файлы с потенциально огромными количествами или некорректными ценами.
