# ECOInter — Market Analyzer

Локальная аналитическая платформа для рынка Eco. В текущей исходной версии репозиторий был пустым; этот проект создаёт frontend, backend, SQLite-хранилище, нормализованную модель предложений и два независимых поисковых алгоритма.

> **Состояние GoodPrice:** на 10 ноября 2026 года соединение с `http://188.235.146.195:3001/plugin/GoodPrice` при прямой проверке завершилось `ECONNREFUSED`. Поэтому фактический API, внутренние HTTP-запросы страницы, авторизация, токены, пагинация, лимиты и семантика цен пока не подтверждены. Приложение не придумывает эти сведения и не создаёт фиктивный рынок. Подробности: [`docs/goodprice-api.md`](docs/goodprice-api.md).

## Что реализовано в этой версии

- React + TypeScript + Vite: адаптивная тёмная аналитическая панель и разделы обзора, возможностей, конструктора маршрутов, товаров, истории, симуляции, серверов, журнала и настроек.
- Fastify API на `127.0.0.1`.
- SQLite + Drizzle schema; сохранение серверов, предложений, снимков истории, событий и настроек.
- Менеджер игровых серверов: добавление, удаление, отдельные URL, интервал обновления, проверка источника.
- Защищённое хранение токена через AES-256-GCM при заданном `ECOINTER_MASTER_KEY`. Токен не передаётся источнику до подтверждения реального формата авторизации.
- Импорт нормализованных JSON-снимков по внутреннему контракту ECOInter.
- Независимый поиск прямых сделок по глубине предложений.
- Независимый поиск многоэтапных валютных циклов через последовательности товаров.
- Точная фиксированная денежная арифметика на `bigint`, без JS floating point для расчётов движка.
- Комиссии/налоги по серверам, фильтрация устаревших котировок и отдельное обозначение справочных цен.
- Межсерверные разницы отмечаются как неисполняемые, пока перенос активов между рынками не подтверждён.
- 13 автоматических тестов, включая пример 150 Relax → 200 Gold → 500 Relax.

Некоторые разделы интерфейса пока имеют ограниченный объём: симуляция сохраняет виртуальные сценарии и введённую фактическую прибыль, но не исполняет игровые ордера; настройка комиссий через UI, автоматическое расписание синхронизации и графики прогнозирования требуют дальнейшей реализации после подтверждения реального источника данных.

## Требования

- Node.js 20 или новее.
- pnpm 9+ (или npm).
- Windows 10/11, Linux или macOS.

## Установка и запуск на Windows

```powershell
cd ECOInter
corepack enable
pnpm install
Copy-Item .env.example .env
```

Сгенерируйте отдельный мастер-ключ и вставьте его в `.env` в значение `ECOINTER_MASTER_KEY`:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Либо запустите `start-windows.bat` двойным щелчком.

Запуск frontend и backend:

```powershell
pnpm dev
```

Откройте `http://127.0.0.1:5173`. Backend доступен на `http://127.0.0.1:3000/api`.

Запуск проверок:

```powershell
pnpm test
pnpm typecheck
pnpm build
```

При использовании npm:

```powershell
npm install
npm run dev
npm test
npm run build
```

## Подключение рынка

1. Откройте «Серверы» и добавьте игровой сервер и URL GoodPrice.
2. Нажмите «Проверить источник». На данном этапе эта операция проверяет только доступность указанного URL; она не утверждает, что API или авторизация уже известны.
3. После исследования фактического API GoodPrice необходимо реализовать парсер именно его реального ответа.
4. До этого момента можно импортировать подготовленные реальные данные в JSON по контракту [`ecointer.market.v1`](docs/market-model.md). Демо-предложения не создаются.

## Локальные данные

По умолчанию база находится в `./data/ecointer.sqlite`. Путь можно изменить через `DATABASE_PATH`. Не добавляйте `.env`, базу данных и резервные копии с секретами в Git.

## Архитектура и ограничения

См. [`docs/architecture.md`](docs/architecture.md), [`docs/arbitrage-engine.md`](docs/arbitrage-engine.md), [`docs/security.md`](docs/security.md), [`docs/settings.md`](docs/settings.md) и [`docs/troubleshooting.md`](docs/troubleshooting.md).

Автоматическая покупка и продажа не реализованы: приложение только анализирует предложения и моделирует потенциальные сделки. Отсутствие данных не трактуется как нулевая цена или отсутствие конкурентов.
