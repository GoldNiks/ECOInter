# ECOInter — Market Analyzer

Локальная аналитическая платформа для рынка Eco. Она загружает предложения из GoodPrice, сохраняет снимки и историю на компьютере пользователя и ищет прибыльные торговые возможности — включая многошаговые последовательности, в которых исходный капитал проходит через несколько товаров и валют и возвращается с более высокой стоимостью.

## Что реализовано

- React + TypeScript + Vite: обзор, прямые возможности, конструктор маршрутов, товары, история цен, симуляция, серверы, журнал и настройки.
- Fastify API и локальная SQLite + Drizzle.
- Адаптер GoodPrice: `GET /api/v1/plugins/GoodPrice/stores`, авторизация через `X-Auth-Token`, разбор `Stores/AllOffers` и нормализация предложений.
- Сохранение world ticket в локальном хранилище с AES-256-GCM; случайный ключ `data/master.key` создаётся автоматически при первом запуске.
- Ручная и периодическая синхронизация рынка по интервалу сервера.
- История снимков цен, локальный журнал подключений и ошибок.
- Независимый поиск прямых сделок и многошаговых циклов;
- отдельные варианты сделок для каждой пары магазинов, а не одна агрегированная сделка на товар и валюту;
- ранжирование по чистой прибыли, дистанции между магазинами и глубине задействованных заявок;
- ручная привязка координат X/Z магазинов и подтверждение совместимости отдельных товаров профессиональных рынков.
- Фильтрация заявок на приём предметов у распознанных профессиональных рынков, если совместимость с их хранилищем не подтверждена.
- Фиксированная денежная арифметика на `bigint`, фильтрация устаревших котировок и настройка комиссий/налогов.
- Межсерверные разницы помечаются как неисполняемые, пока не подтверждён способ переноса активов между серверами.

Схема GoodPrice и способ получения world ticket описаны в [документации API](docs/goodprice-api.md). Исследование основано на независимой реализации с примерами ответов плагина. Совместимость и авторизация конкретного игрового сервера подтверждаются только фактическим ответом его API после проверки world ticket.

## Требования

- Node.js 20 или новее.
- pnpm 9+.
- Windows 10/11, Linux или macOS.

## Запуск на Windows

Распакуй проект и запусти `start-windows.bat`. Скрипт проверит Node.js, установит зависимости, создаст локальный `.env` при отсутствии и запустит backend вместе с frontend.

Открой `http://127.0.0.1:5173`. Окно терминала должно оставаться открытым во время работы приложения.

Также можно запустить вручную:

```powershell
corepack pnpm install
corepack pnpm run dev
```

Проверки проекта:

```powershell
corepack pnpm test
corepack pnpm typecheck
corepack pnpm build
```

## Подключение GoodPrice

1. Открой «Серверы», добавь сервер и укажи URL страницы GoodPrice, например `http://HOST:PORT/plugin/GoodPrice`.
2. Открой GoodPrice в игре, затем DevTools встроенного браузера → **Application → Local Storage → worldTicketData** и скопируй значение `worldTicket`.
3. Вставь world ticket в поле сервера и нажми «Сохранить токен». ECOInter автоматически создаёт локальный ключ шифрования; отдельно создавать мастер-ключ не нужно.
4. Нажми «Проверить API», затем «Синхронизировать рынок». После успешного ответа карточка покажет статус «Рынок синхронизирован», а разделы товаров, истории и анализа получат реальные предложения.
5. Токен действует около 24 часов. При HTTP 401/403 скопируй новый world ticket и сохрани его вместо старого.

**Важно:** указанный адрес использует HTTP. Локальное шифрование защищает токен в базе, но не в сети. Не передавай world ticket по недоверенной сети; предпочтителен HTTPS.

## Как считается рынок

GoodPrice `Buying=false` означает, что магазин продаёт товар игроку; в ECOInter это `action: "buy"`. `Buying=true` означает, что магазин покупает товар у игрока; это `action: "sell"`. Цена GoodPrice является ценой за единицу, а ECOInter хранит общую стоимость доступного количества.

Пустые и отключённые предложения, нулевые количества и sentinel-цены фильтруются. Детали полей и ограничения API приведены в [docs/goodprice-api.md](docs/goodprice-api.md).

ECOInter анализирует последовательности сделок, но не отправляет игровые ордера и не покупает/продаёт автоматически. Межсерверная разница не считается исполнимым маршрутом без подтверждённого механизма переноса предметов или валюты.

## Локальные данные

По умолчанию база: `./data/ecointer.sqlite`. Ключ токена: `./data/master.key`. Папка `data/`, `.env` и локальные секреты исключены из Git. Не удаляй `master.key`, пока в базе хранятся зашифрованные токены.

## Ограничения

GoodPrice не предоставляет фактическую историю транзакций, временные метки отдельных офферов, координаты магазинов или вес предметов. Координаты X/Z для оценки минимальной дистанции нужно ввести вручную в настройках. Время наблюдения фиксируется при получении каждого снимка. Текущая версия исключает покупателей с нулевым балансом, но не учитывает полностью общий кошелёк одного владельца между несколькими магазинами; такие случаи следует проверять вручную.

Симуляция ECOInter является бумажной: она сохраняет предполагаемые и введённые фактические результаты, но не взаимодействует с игровыми ордерами.
